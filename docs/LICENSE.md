## 為什麼與程式碼分開

repo 其餘部分走 Apache-2.0（見根目錄 `LICENSE`）。這裡不同，有兩個理由：

1. **這些是散文不是程式。** Apache-2.0 的用語（衍生著作、專利授權、目的碼形式）
   套在一篇談「帳不是債」的文章上語意很奇怪。
2. **相同方式分享是刻意的。** 這些原則的價值在於它們**否決**了什麼。
   若有人引用、改寫、擴充它們，那份改寫也應該保持開放，而不是變成某個閉源產品
   的內部文件。
